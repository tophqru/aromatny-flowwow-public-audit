# Ароматный букет — публичный каталог для независимого аудита

Это публичная **контрольная копия товарных данных** собственного магазина «Ароматный букет» на Flowwow, не функционирующий интернет-магазин.

**435 оригинальных JPEG** перечислены с исходными URL, SHA-256 и размерами в JSON. Их загрузка в репозиторий автоматизирована; до подтверждённого успешного GitHub Actions нельзя объявлять фотографии физически перенесёнными.

Наблюдавшиеся цены и статусы устаревают. Полные описания пока отсутствуют. Все позиции закрыты для продаж. Товар с кодом №4183 исключён владельцем. Полнота скрытого и архивного Seller-каталога неизвестна.

**Без лицензии:** публикация файлов для сверки не является разрешением на свободное коммерческое использование третьими лицами.
