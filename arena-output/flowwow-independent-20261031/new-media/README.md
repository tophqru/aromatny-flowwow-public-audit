# Новые оригинальные изображения

В этом запуске новые оригинальные фотографии **не добавлены**: `0 JPEG`, `0 bytes`.

Причина: нет интерактивного браузера для достоверного перехода к точным товарным страницам, подтверждения canonical seller и полной галереи. Существующие 435 JPEG уже находятся в `data/flowwow/items/` исходного публичного репозитория и не скачивались повторно.

Эта папка намеренно не содержит исходных фотографий. Будущие новые файлы следует добавлять только после проверки exact seller/product URL, порядка галереи, source URL, SHA256, bytes, MIME и разрешений изображения; фото из отзывов не включать.
