## Главные находки

1. У семи приоритетных SKU нет количественного состава, описания и размеров; они не доказаны пустыми или заброшенными.
2. У `avtorskiy-buket-67899` размеры хранятся как `{width: null, height: null}`, тогда как остальные 11 пробелов — `null`; валидных пар всё равно 54.
3. `kompoziciya-aromatnyh-ogromnyh`: 35 пионов в каталоге против 23 в индексном evidence — конфликт не разрешён автоматически.
4. `buket-hrizantem-mattiola-romas`: маттиола есть в названии, но отсутствует в сохранённом составе.
5. 435 JPEG содержат 426 уникальных SHA256: 8 групп точных повторов внутри 7 галерей, 9 повторных вхождений; это не доказательство ошибки живой галереи.
6. Сохранённые исторические цены/статусы расходятся с более поздними наблюдениями и индексами; текущая витрина не проверена.
7. 55 кандидатов остаются `UNVERIFIED`; отображаемое имя магазина не заменяет точный canonical seller link.
8. Исключённый владельцем SKU №4183 не возвращён; все разрешения на продажу остались `false`.

## Воспроизведение

Из корня репозитория, с Python 3.11+ и Pillow:

```bash
python -m pip install 'Pillow>=10,<12'
python arena-output/flowwow-independent-20261031/scripts/audit_offline.py
python arena-output/flowwow-independent-20261031/scripts/verify_delivery.py
```

Скрипты не обращаются к Flowwow и не скачивают фотографии. Подробные команды, результаты и неисполненные тесты приведены в `QA.md`.
